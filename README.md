# ♞ 小马战术乐园 · CheerUp Chess

陪 5 岁孩子听懂国际象棋战术，在棋盘上动手发现小妙招。

**网站：[chess.cheerup.tech](https://chess.cheerup.tech)**

## 可以做什么

- 16 个战术主题的中文小故事、亲子提问和记忆小口诀，支持浏览器中文朗读。
- 16 章各 6 道原创入门变式，共 96 道。每个主题使用基础图式、起始位置变化与镜像，帮助重复辨认；不是 96 个完全不同的组合，也不是书中题库。部分练习用明确标注的示范应手展示概念，不宣称涵盖对方所有防守。
- 打开题目即可点击或拖动走棋，显示可走格和上一步；双方按顺序播放移动动画，对手应手前稍作停顿。区分非法走法与未达到本题目标的合法走法。
- 自动走对方应手、分层提示、升变选择、无计时星星鼓励。
- 本机进度、按 1～3 天安排复习、完整 JSON 备份与恢复。
- 家长在可视化棋盘摆题、录制双方解答，保留章节和原书题号。
- 高级用户批量导入带 FEN、SAN 解答的 JSON，支持正确答案分支。

每章都可听故事、聊引导问题并开始原创小题；家长也可录入对应章节的个人题目。

## 本地运行

需要 Node.js 24+、npm。

```sh
npm ci
npm run dev
```

浏览器打开终端显示的本地地址。生产版本：

```sh
npm test
npm run build
npm run preview
```

`dist/` 是可部署到任意静态主机的完整网站。无运行时 API、服务端数据库或付费 AI 依赖。

## 家长怎样录入《马头书》的题

1. 网站 → **家长入口 → 摆棋盘，录一道书题**。
2. 对照完整棋图，用棋子按钮在棋盘上摆棋；橡皮擦可移除棋子。要包含双方的王。
3. 填写章节、原书题号、儿童题名、引导问题、提示和完成解释。
4. 点“标记引导答案格”，选择孩子应找出的守卫、目标或格子。
5. 设置先手方，点“开始录答案”。按书上的解答交替走双方棋子，录到书中主线结束；最后一步也可以是对方应手。
6. 保存后，题目出现在对应章节。及时从家长入口下载完整备份。

章节首页的 5×5 简图可能省略其他棋子；请使用完整棋题，不能假设简图就是完整合法对局。录入前请核对书中答案。系统检查走法合法性，不自动证明战略最优性。

初版不包含拍照识别、PDF 自动识别或原书全题库下载。家长不用先寻找第三方题库。

## 内容与准确性

题目按显式解答树判断，不把任意引擎评价当作课堂答案。支持同一孩子走法后的多个后续正确分支；同一节点的对方应手必须一致。其他合理解答可通过导入文件扩展。内置的引离、引入有弃车步骤，适合家长带着演示。

编辑器录制一条主线；文件导入支持多条分支。详见 [题目格式](docs/CONTENT.md)。

## 本地数据

LocalStorage 键为 `cheerup-chess-v1`。没有登录、广告、分析追踪、公开排名或儿童资料收集。进度保存在当前浏览器；不同域名/浏览器/设备不能自动同步。备份包含全部自录题和进度。设备更换前请下载备份，在新设备上恢复。

HTTP 静态托管服务器仍可能记录普通访问日志；浏览器语音由系统/浏览器提供，是否使用在线语音取决于设备。网站不上传棋题和学习记录。

总自录题上限 500 道、2.5 MB，单次题目文件 2 MB，完整备份 3 MB（均按 UTF-8 字节计）。无效导入会整体拒绝，不会部分写入。存储无法读取时不覆盖原数据，会提示家长处理。

## 项目结构

- `src/content.js`：16 章故事、亲子提问和前四章原创图式；`src/original-extra.js`：第 5–16 章原创入门变式。
- `src/runner.js`：棋题解答树和自动应手。
- `src/import.js`：内容格式、完整分支与合法性检查。
- `src/storage.js`：进度、复习、备份。
- `src/editor.js`：编辑器局面权限处理。
- `src/board.js`：支持点击、拖动与键盘的棋盘。
- `src/main.js`：地图、课程、练习、家长入口与录题流程。
- `tests/`：内容和核心行为检查。
- `deploy/`、[部署说明](docs/DEPLOY.md)：腾讯云现有服务器的静态网站部署。

## Lichess 延伸练习

每张战术地图卡片和每个章节故事页都提供 Lichess 练习入口。对应关系在 `src/lichess.js` 维护，参考官方 [主题目录](https://lichess.org/training/themes)。直接对应主题与仅覆盖部分内容的“相关练习”明确区分，外部站点在新标签页打开，进度不计入本站。

## 棋盘与开源许可

练习棋盘直接复用 [Lichess Chessground](https://github.com/lichess-org/chessground)，提供点击、拖动、合法落点和走子动画。原书 5×5 示意图通过裁剪显示，棋子坐标和走法判断仍使用真实棋盘。题目规则由 chess.js 和本项目答案判断器负责。

包含 Chessground 的完整应用按 GPL-3.0-or-later 发布，见 LICENSE 和 THIRD_PARTY_NOTICES.md；原有代码的 MIT 授权保留在 LICENSE-MIT。家长摆棋编辑器暂保留原有棋盘。


## 服务器托管题目

部署时可在服务器 `/var/www/cheerup-chess/shared/site-data/puzzles.json` 放置单独管理的 `{ "puzzles": [...] }` 文件。发布脚本在每个静态版本中建立链接，前端启动时读取并验证；这些内容不进入 Git、构建产物或公开原创题库。该文件通过本站公开读取，适合站点管理者明确提供给访客的练习内容。没有文件时只使用内置题和本机录题。

云端题目以稳定 ID 与本机录题合并去重，本机同 ID 修改优先。学习进度仍保存在各自浏览器，云端题目不会覆盖进度。自己在编辑器录入的题目不会自动上传。引导问题保留为观察和讨论提示，走棋不需要先点击引导答案。

练习棋盘使用 Chessground 10.5.0，落点对错图标直接调用官方 glyphToSvg，再由官方 autoShapes 绘制。行棋记录面板为本站的轻量适配，支持正确走法、错误尝试、对手应手及局面回看；不声称它是独立的 Lichess 官方记录组件。构建环境要求 Node.js 24 或以上。

云端托管题库支持最多 5000 条练习、10 MB，分批校验并跨批检查重复 ID；本机导入与备份限制保持原有规则。扫描识别产物与书题数据仍保存在 work/、outputs/，不进入 Git。

## 分值与错题本

章节练习先显示原创入门题，再按原书题号从小到大排列，同题白先在黑先之前；可按分值筛选，完成后的下一题也遵循相同顺序；做题页标题旁也显示分值。原书分值与完成星星分别显示，原创入门练习按 1 分安排。旧题库可从 `bookRef` 中的“书中难度 N”读取分值。

合法但不符合本题答案的走法会立即记入本机错题本，不需要完成整题。以后再独立完成、获得 3 星，也不会自动移除这条错题记录。错题本保存首次出错时间、最近出错时间及累计出错次数，并随家长备份一起导出、恢复；旧版备份仍可恢复。进度和错题记录各支持最多 5000 条。
