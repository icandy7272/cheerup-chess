# Project workspace

This directory is the canonical CheerUp Chess project root selected by the user.
Keep project source, documentation, tests, deployment scripts and project-specific intermediate files under this root. Do not create parallel working copies under Documents/Codex.

Use npm test and npm run build before publishing. Keep imported family/book exercises and credentials out of Git. The public built-in exercises must be original or have explicit redistribution rights.

Deploy to the user-authorized Tencent Cloud server and chess.cheerup.tech. Use GitHub connector or CLI; do not use the user’s Chrome for GitHub operations.
