# 题目文件格式

家长可优先使用可视化录题。批量导入在“家长入口 → 已有电子题目”中进行。

文件为 UTF-8 JSON，顶层数组或 `{ "puzzles": [...] }`。可从家长入口下载有效示例。

```json
{
  "puzzles": [{
    "id": "family-001",
    "chapter": 1,
    "title": "找到小守卫",
    "bookRef": "第 1 章 · 第 001 题",
    "fen": "6k1/8/8/3r4/3p4/8/6B1/3R2K1 w - - 0 1",
    "lines": [["Bxd5+", "Kf8", "Rxd4"]],
    "question": "谁在保护 d4 的黑兵？",
    "answers": ["d5"],
    "hints": ["找找黑车。", "先用象吃守卫，再用车吃兵。"],
    "explanation": "先吃保护兵的车，再吃兵。",
    "source": "个人练习，请填写实际来源"
  }]
}
```

例题为本项目原创示例，`bookRef` 字符串只演示填写方式，不表示对应真实原书题号。

- `id`：1～80 个英文字母、数字、短横线或下划线，必须唯一，拒绝 Object.prototype 保留键。
- `chapter`：1～16；`title`、`question`、`explanation`、`source` 均为非空文本，最多 500 字符。
- `fen`：合法完整局面，必须有双方的王。未轮到走棋的一方不能已经被将军。
- `lines`：标准 SAN 格式（包含必要的将军/将死符号），1～16 条，单条最多 31 个半回合。第一个半回合就是孩子应走的一步，奇数索引位置是自动应手。每条可在孩子的一步或对方的自动应手后结束；网站播放完最后一步才判定完成。
- 分支只在孩子的选择处变化；同一前缀的自动应手必须一致。禁止某条答案是另一条答案的前缀。
- `answers`：引导问题的一个或多个正确格子，如 `d5`；不是棋谱答案。
- `hints`：1～5 条非空文字，单条最多 500 字符。
- `bookRef`：可选，最多 100 字符。

文件中所有文本都作为纯文本展示；不能执行 HTML 或脚本。导入只接收明确字段，不保留其他元数据。合法性验证不能代替教练对战术主题、对方最强防守和最终收益的核对。

章节：1 消除保护；2 引离；3 引入；4 闪击；5 开线；6 腾挪；7 射线攻击；8 拦截；9 阻塞；10 破坏兵形；11 兵升变；12 中间着；13 逼和；14 子力限制；15 长将（长捉）；16 战术组合。

## 局部教学示意图

个人导入题可显式填写 `"diagram": true`。该模式显示 d4～h8 的 5×5 区域，保留照片或教材中实际展示的棋子，允许白王未展示，不会补入虚构棋子。必须有且仅有一个黑王，所有展示棋子、引导答案和主线走法均位于该区域；不支持王车易位或吃过路兵权限。没有此标记的普通题仍要求双方的王和完整合法局面。

局部图仅用于按教材主线演示，不代表可以还原或判断未展示部分的完整对局。页面会始终显示局部图提示。解答文件与备份都会保留此标记。当前可视化摆棋编辑器仍用于完整局面，局部图通过文件导入。
