The complete application source and dependency lockfile are available at https://github.com/icandy7272/cheerup-chess. Existing CheerUp Chess code remains additionally available under the original MIT grant in LICENSE-MIT.

Used directly as the exercise board, including its base CSS, bundled Cburnett SVG piece stylesheet, and official glyphToSvg check/cross feedback icons. Chessground includes Colin M. L. Burnett's chess pieces, available under GPL and other licenses; this application uses them under GPL.
- **chess.js** 1.4.0 — Jeff Hlywa and contributors, BSD-2-Clause. See the package's LICENSE in node_modules/chess.js.

Personal imported book exercises are browser-local user data, excluded from this repository and from the public built-in exercise library.
